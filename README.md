# Alihan Kutlu | Photo Media Works — Portfolyo & CMS Sistemi

Alihan Kutlu'nun (**Lal Fotoğrafçılık Bilişim Prodüksiyon Turizm Reklam ve Tanıtım Hizmetleri Ltd. Şti.**) talepleri ve vizyonuna özel olarak hazırlanmış; geleneksel web sitesi hantallığından uzak, **tıpkı telefonlarımızın kendi fotoğraf galerisi gibi basit ve akıcı**, parmak hareketleriyle (swipe) gezilen mobil öncelikli portfolyo ve canlı yönetim paneli (CMS) prototipi.

---

## 🌟 Öne Çıkan Özellikler

### 1. Telefon Galerisi Sadeliği & Akıcılığı (iOS/Android Photos UX)
* **Kare & Kadraj Izgara Modları:** Telefon albümünde olduğu gibi hızlı kare ızgara veya orijinal kadraj görünümü.
* **Tam Ekran Swipe Gezintisi:** Fotoğrafa dokunulduğunda tam ekran açılır; parmakla sağa/sola kaydırarak sıfır gecikmeyle gezilir.
* **Aşağı Çekip Kapatma (Pull-Down to Dismiss):** Fotoğrafı aşağı kaydırınca yumuşak animasyonla galeriye geri döner.
* **Çift Dokunma & Zoom:** Detayları incelemek için çift dokunma / büyüteç butonu.
* **Alt Film Şeridi (Thumbnail Scrubber):** iPhone fotoğraflardaki gibi ekranın altındaki küçük önizleme şeridiyle istenen kareye anında atlama.
* **Otomatik Slayt Gösterisi:** Tek tuşla albümü kesintisiz izleme.

### 2. Düğün Ağırlıklı Değil, Kapsamlı Prodüksiyon Portfolyosu
Alihan Bey'in `www.alihankutlu.com` sitesindeki gerçek 152 fotoğraf ve 23 video ile genel portfolyo sıralaması:
1. **Kurumsal Portreler & İş Dünyası**
2. **Ürün, Tanıtım, Gastronomi & Sanayi**
3. **Photo Media Works — Moda & Kreatif**
4. **Etkinlik, Konser & Sahne Çekimleri**
5. **Özel Konsept & Portre Seçkisi**
6. **Düğün Fotoğrafları Seçkisi (WPPI & WPE Ödüllü)**
7. **Ece & Oğuz — Düğün Hikayesi**
* Uluslararası WPPI, WPE ve Magic Lens ödülleri (13 gümüş madalya ve derece) ve biyografi bölümü.

### 3. Video Galerisi & Entegre Oynatıcı (23 Gerçek Video)
* Tanıtım filmleri, etkinlik çekimleri, moda klipleri ve düğün hikayeleri.
* Sayfa değiştirmeden açılan, "Önceki / Sonraki" butonlarıyla akıcı gezilen tam ekran video oynatıcı.

### 4. Canlı Yönetim Paneli (CMS) — Webciye Bağımlı Olmadan Güncelleme
* **Albümleri & Sıralamayı Yönet:** `↑ / ↓` tuşlarıyla albüm sırasını değiştirme veya silme.
* **Albüm İçine Fotoğraf Ekle / Sil:** Seçilen albüme sürükle-bırak ile anında yeni fotoğraflar yükleme, kapak fotoğrafı seçme veya kare silme.
* **Yeni Albüm Oluştur:** Çekim sonrasında fotoğrafları topluca seçip anında yeni albüm olarak yayına alma.
* **Video Ekle & Yönet:** YouTube linki yapıştırıldığında kapağı otomatik çeken video ekleme paneli.
* **Kalıcı Tarayıcı Hafızası:** Alihan Bey demoyu denerken yaptığı tüm değişiklikler tarayıcısında korunur; dilediğinde "Orijinal Site Verilerine Sıfırla" butonuyla ilk haline döndürebilir.

## 🚀 GitHub Pages Üzerinde Yayınlama

Proje tamamen saf HTML5, CSS3 ve JavaScript ile yazılmıştır; harici veritabanı veya sunucu gerektirmez:

```bash
git init
git add .
git commit -m "Alihan Kutlu Photo Media Works Portfolyo & CMS"
git branch -M main
git remote add origin https://github.com/anilmetey/alihan-kutlu.git
git push -u origin main
```

GitHub'da repo ayarlarından (**Settings -> Pages -> Deploy from a branch: main**) açtığınızda:
**`https://anilmetey.github.io/alihan-kutlu/`** adresi üzerinden doğrudan Alihan Bey'e gönderilebilir.
